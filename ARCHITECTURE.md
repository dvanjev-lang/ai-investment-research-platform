# Architecture

## Current (Development)

```
Frontend: Next.js 14 on localhost:3000
Backend:  FastAPI on localhost:8000
Database: PostgreSQL (local or Supabase)
AI:       OpenAI API (GPT-4o + text-embedding-3-small)
Storage:  Local filesystem (demo) / S3 (production)
```

## Production Target (AWS)

```
Frontend:  Vercel (Edge CDN)
Backend:   AWS ECS/Fargate (Docker container)
Database:  Supabase (PostgreSQL + pgvector)
Storage:   AWS S3 (document uploads)
Monitoring: AWS CloudWatch
```

## Data Flow

```
User searches NVDA
     ↓
Next.js → GET /api/v1/companies/search?q=NVDA
     ↓
FastAPI → FinancialDataProvider.search_companies()
     ↓
MockProvider (or FMPProvider) → returns CompanySearchResult[]
     ↓
Frontend renders search dropdown
```

## AI/RAG Flow

```
User asks: "What were NVDA's main revenue drivers?"
     ↓
POST /api/v1/research/query
     ↓
Research Planner: classifies question type
     ↓
Financial Data Agent: fetches structured financials from DB/provider
     ↓
Document Agent: searches uploaded documents (keyword → pgvector in prod)
     ↓
Evidence Assembly: combines financial context + document excerpts
     ↓
OpenAI GPT-4o: generates answer with strict system prompt (no advice)
     ↓
Citation Validator: validates all cited sources
     ↓
Response: answer + citations + agent_trace
```

## Security Model

- API keys stored server-side only (never in frontend bundle)
- CORS configured to allowed origins only
- Input validation via Pydantic on all endpoints
- Rate limiting: add slowapi in production
- Database: Supabase Row Level Security for multi-user
- No financial advice generated by design (system prompt enforcement)
